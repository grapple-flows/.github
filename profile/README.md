## Grapple Flows

Grapple Flows is a free BJJ flowchart app that turns voice notes and videos into visual maps of jiu-jitsu techniques, positions, and transitions you can study, edit, and share.

**[grappleflows.com](https://grappleflows.com)** · [Try it without an account](https://grappleflows.com/try) · [Community flowcharts](https://grappleflows.com/explore) · [Blog](https://grappleflows.com/blog/) · [Instagram](https://www.instagram.com/grappleflows) · [Discord](https://discord.gg/B8j8CmVHSD)

### Open source

The same code and data behind the free tools on grappleflows.com. MIT licensed, no dependencies, and each widget drops onto any website with one script tag.

| Repo | What it is |
| --- | --- |
| [bjj-timer](https://github.com/grapple-flows/bjj-timer) | BJJ round timer web component: presets, IBJJF match times by belt, 10-second warning, fullscreen, wake lock |
| [bjj-scoreboard](https://github.com/grapple-flows/bjj-scoreboard) | IBJJF scoreboard web component: points, advantages, penalties, automatic tiebreaks, match clock |
| [bjj-bracket](https://github.com/grapple-flows/bjj-bracket) | Tournament bracket generator: single and double elimination, round robin, teammates kept apart, IBJJF podium |
| [bjj-data](https://github.com/grapple-flows/bjj-data) | IBJJF and ADCC weight classes, legal techniques by ruleset, IBJJF belt requirements, and a BJJ position vocabulary as JSON (data CC BY 4.0) |

### Free tools

No account, no ads. Five of them can go on a gym or event website with a copy-and-paste code ([how](https://grappleflows.com/tools#embed)).

| Tool | What it does |
| --- | --- |
| [BJJ round timer](https://grappleflows.com/timer) | Round and rest presets, IBJJF match times by belt, fullscreen for the gym TV |
| [IBJJF scoreboard](https://grappleflows.com/bjj-scoreboard) | Points, advantages, penalties, tiebreaks, and a belt-timed clock |
| [Bracket generator](https://grappleflows.com/brackets) | Single elimination, double elimination, and round robin for in-house comps |
| [Weight classes](https://grappleflows.com/bjj-weight-classes) | Every IBJJF and ADCC class in pounds and kilograms, with a calculator |
| [Legal techniques](https://grappleflows.com/bjj-legal-techniques) | What's legal by belt, age, and gi or no-gi |
| [Belt requirements](https://grappleflows.com/bjj-belt-requirements) | IBJJF minimum age and time at each belt |

### About

Built by Justin, a software engineer and competitive grappler (2× IBJJF American National Champion). The first version, BuddyTape, launched in 2019 after Ffion Davies showed how she planned matches with paper flowcharts. Questions or corrections: hello@grappleflows.com.
